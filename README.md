# Quiz de perguntas sobre geografia
O Quiz de perguntas tem foco na UI. Possui muitas estilizações, animações, timer de perguntas e um pequeno sistema de pontuação. Fiz com o objetivo de aprimorar meus conhecimentos em Java e sua API gráfica JavaFX
## Tecnologias utilizadas
- **JavaFX**: API para construção de interface gráfica
- **CSS**: Utilizado para estilizar componentes da interface

## Como executar
### Primeiro, certifique-se de que tem o maven instalado 
### Em seguida, baixe o repositório em sua máquina:
